# Rillstone Stream Telemetry Analyzer

An offline analysis toolkit for captures produced under earlier revisions of the Rillstone Stream Telemetry Protocol. It supports the **RSTP-5** and **RSTP-6** frame layouts and their capture formats.

Revision 9 (RSTP-9) introduced 9-bit cyclic tags and a different trailer layout; this toolkit cannot decode RSTP-9 streams and is not an RSTP-9 implementation.
