# Rillstone Nexus

Rillstone Nexus is Nimbus Rill's multi-tenant event streaming platform. It provides durable ingest queues, tenant isolation and log compaction for product telemetry pipelines.

The name Rillstone comes from our parent company, Nimbus Rill. This product is a streaming infrastructure platform and does **not** implement the Rillstone Stream Telemetry Protocol; it does not provide RSTP framing, pulse heartbeats or revision negotiation.
