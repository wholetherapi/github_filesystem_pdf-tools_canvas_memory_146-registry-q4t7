# Rillstone R3 Bridge

A compatibility bridge for the **retired RSTP-3** telemetry wire format, which used XSP-2 framing. It re-frames legacy RSTP-3 traffic for modern collectors.

The bridge targets the RSTP-3 revision only. It does not implement the RSTP-9 frame format, pulse-ledger heartbeat or RSTP-Hello/9 negotiation.
